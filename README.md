# beauty-agent

ИИ-администратор для салонов красоты: круглосуточно отвечает клиентам в мессенджерах и записывает их к мастеру через YCLIENTS.

> Статус: в разработке, октябрь — декабрь 2026.

## Проблема

- Клиенты пишут в мессенджеры вечером и в выходные, а администратор отвечает только в рабочее время и между звонками: часть заявок теряется.
- Большая часть сообщений — одни и те же вопросы: цены, свободные окна, адрес, как подготовиться к процедуре.
- Запись переносится из переписки в CRM вручную, отсюда ошибки и двойные записи.

## Решение

Агент на LLM понимает свободный текст, берёт услуги, мастеров и свободное время из YCLIENTS, создаёт запись и передаёт сложные случаи администратору.

## Быстрый старт

Нужны Python 3.12, [Poetry 2.x](https://python-poetry.org/docs/#installation) и GNU Make (на Windows: `winget install ezwinports.make`).

```bash
git clone https://github.com/Bananas1631/Ai-beauty-agent.git
cd Ai-beauty-agent
make install   # зависимости и git-хуки
make check     # линтер, типы и тесты
```

Все команды — `make help`.

## Данные и секреты

В репозитории нет реальных данных салонов и клиентов: тесты работают на обезличенных и сгенерированных данных. Ключи и пароли хранятся только в `.env`, который не попадает в git; перед каждым коммитом gitleaks ищет случайно добавленные секреты.
