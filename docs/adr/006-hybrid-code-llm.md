# ADR 006. Гибрид «код + LLM»: время и цену даёт код, модель только разговаривает

- Статус: принято
- Дата: 2026-10-31

## Контекст

LLM придумывает правдоподобные факты: цену «примерно 2 000 ₽», свободное время «в 15:00».
Для салона это хуже, чем отсутствие ответа: клиент приходит в занятое время или спорит о цене.
Вторая угроза — гонка: два клиента подтверждают одно окно одновременно, или клиент дважды пишет «да».

## Решение

1. **Факты — только из инструментов.** Цены и услуги — `find_service` из каталога, время —
   `find_free_time` из CRM. Выходной guardrail сверяет каждую цену и время в ответе с результатами
   инструментов диалога; неподтверждённый ответ заменяется безопасным.
2. **Запись — по номеру варианта.** Движок сохраняет предложенные слоты в Redis под номерами 1–3;
   `book` принимает номер, а не время. Модель не может записать на время, которого не предлагали.
3. **Ровно одна запись.** Ключ идемпотентности = хеш «салон + диалог + слот»; состояния
   «в процессе» и «готово» с результатом. Повторное «да» возвращает ту же запись.
   После того как CRM создала запись, никакая ошибка не снимает ключ.
4. **Перепроверка перед записью.** `check_slot` в CRM без кэша; время заняли — новые варианты.

## Уровень изоляции

Запись в БД — одна транзакция на уровне **READ COMMITTED**. От гонки защищают:
- уникальный ключ `(salon_id, idempotency_key)` — два подтверждения одного варианта;
- ограничение исключения `ex_bookings_master_overlap` (GiST, `tstzrange &&`) — две пересекающиеся
  записи одного мастера, даже если ошибка в коде.

SERIALIZABLE отвергнут: при конкурентных записях он даёт ошибки сериализации, которые нужно
повторять, а повтор после созданной в CRM записи опасен. Ограничения БД дают ту же гарантию
для нашего инварианта без повторов и с понятной ошибкой.

## Последствия

- Инварианты «нет записи на непредложенное время» и «нет цены вне каталога» обеспечивает код,
  поэтому в evals их порог — ровно 100%.
- Модель можно менять, не боясь, что она начнёт обещать лишнее: guardrail ловит это на выходе.
