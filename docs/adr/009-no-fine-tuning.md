# ADR 009. Модель сейчас не дообучается

- Статус: принято
- Дата: 2026-10-31

## Контекст

Fine-tuning обещает «модель, которая говорит как администратор салона». Но качество агента
определяют другие вещи: правильные факты, верный вызов инструментов и отказ там, где нужен человек.

## Решение

Не дообучать. Нужное качество дают:
- **промпт** с правилами и версией в файле (`agent/prompts/system_v1.md`) — меняется за минуты;
- **инструменты и guardrails** — факты из кода, а не из весов модели;
- **RAG** по сайту салона — знания конкретного салона без переобучения (блок 5);
- **evals** — измеримое качество на каждом изменении промпта или модели.

Дообучение сейчас вредно: нет размеченных данных (пилотов ещё нет), модель привязалась бы к одному
провайдеру, а каждая смена базовой модели требовала бы нового обучения и новой оценки.

## Когда пересмотреть

- Накоплено **10 000+ размеченных диалогов** с пилотов — тогда оправдан небольшой классификатор
  намерений (запись / вопрос / жалоба / медицина) вместо регулярных выражений и части вызовов LLM.
- Стоимость диалога упирается в цену большой модели, а маленькая дообученная модель
  на evals не хуже — дообучение как способ удешевления.
- Нужен стиль общения конкретной сети салонов, которого не добиться промптом.
