## Что меняется в плане на ноябрь

- Каналы подключаются к уже готовому `ConversationService`: вебхук → очередь → воркер → тот же сервис.
- Офлайн-модель остаётся нижней планкой evals и запасным вариантом для демо без ключей.
- Проверка «функций для резюме»: всё сделанное нужно салону напрямую (запись, ответы, демо для продаж)
  или защищает его (инварианты, 152-ФЗ). Лишнего не найдено.

## Задачи ноября (завести на GitHub по неделям)

- **9–14 ноября**: Celery + RabbitMQ, вебхук Telegram с проверкой подписи и дедупликацией, outbox исходящих.
- **16–21 ноября**: MAX и VK, согласия 152-ФЗ в первом сообщении, админ-бот, запуск пилотов.
- **23–28 ноября**: полный цикл записи (перенос, отмена, напоминания), отчёты салону.

## Точка решения

Договорённостей о пилотах пока нет (демо на реальных салонах не сделаны без токена) —
по плану это значит удвоить число демо в ноябре, как только появится доступ к YCLIENTS.
